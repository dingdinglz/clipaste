clipaste — hardened fork

Paste local clipboard images into Claude Code running on a trusted SSH server.

  • Bearer authentication for clipboard state and image data.
  • Local clipboard left unchanged by default.
  • Image caches expire after one hour by default.
  • Private credentials, bounded HTTP, safer SSH configuration and helper installation.

This fork currently requires a reviewed source build. Upstream Homebrew packages and binary releases do not include these changes. No fork binary release is advertised.

Source and installation · Security model · Agent reference

Only bridge fully trusted accounts. Remote administrators and processes running as the configured account can still access its credential. Images are observed automatically, not only when you press paste. Deletion is not secure erasure.
